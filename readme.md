# Analyse spatio-temporelle des accidents de navires

## Introduction

### Contexte

Ce projet porte sur l’analyse spatio-temporelle des accidents de navires en mer.
Il s’appuie sur des données d’accidents couvrant la période de 2011 à 2025, ainsi que sur des données relatives au
trafic maritime couvrant la période de 2017 à 2020. Le projet se concentre actuellement sur l’Europe.

### Problématique

Dans quelle mesure l’analyse des accidents de navires et de leur répartition dans l’espace et dans le temps permet-elle d’identifier des zones accidentogènes et de prédire leur évolution ?

### Objectifs

L’objectif est d’analyser la répartition des accidents dans l’espace et dans
le temps, puis d’utiliser ces informations afin d’identifier et de prédire les
zones présentant un risque accidentogène accru.

### Approche

Le projet repose sur plusieurs étapes :
- nettoyage et préparation des données ;
- analyse et visualisation ;
- prédiction à l’aide du *Random Forest* ;
- génération de cartes permettant de visualiser les résultats.
